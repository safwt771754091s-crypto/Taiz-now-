# النسخ الاحتياطية (Snapshots)

نظام نسخ محلي يحفظ حالة المشروع كاملة، حتى نستطيع العودة إلى أي نقطة سابقة
إذا حدث تغيير غير مرغوب فيه.

> أُنشئ في 2026-10-12.

## ماذا يحفظ؟
- **شجرة المصدر كاملة** (`source.tar.gz`): كل ملفات المشروع ما عدا `node_modules`
  و`.next` و`.git` و`.run` و`.snapshots` (أي كل ما يمكن إعادة توليده).
- **بيان (manifest.txt)**: التاريخ، الفرع، رقم الالتزام (commit)، الملفات المتغيّرة،
  وبصمة `sha256` للأرشيف للتحقق من سلامته.
- **نسخة قاعدة البيانات** (`db.sql.gz`) عندما تكون قاعدة PostgreSQL متاحة.

## الأوامر
```bash
bash scripts/snapshot.sh                 # أخذ نسخة الآن
bash scripts/snapshot.sh "وصف"           # نسخة مع وصف
bash scripts/snapshot.sh --list          # عرض النسخ الموجودة
bash scripts/snapshot.sh --restore <id>  # استعادة نسخة (تأخذ نسخة أمان قبلها)
```

النسخ تُخزَّن في `.snapshots/` (غير مُدرَجة في Git) ويشير `latest` إلى أحدث نسخة.

## النسخ التلقائي
- **عند أي تغيير في الكود**: `scripts/snapshot_watch.sh` يراقب المشروع كل 30 ثانية
  (قابل للضبط بـ `SNAP_INTERVAL`) ويأخذ نسخة عند أول تغيير يكتشفه.
- **عند كل حفظ (commit)**: خطّاف `.git/hooks/post-commit` يأخذ نسخة تلقائياً.
- **عند تشغيل المشروع**: `scripts/start.sh` يبدأ المراقب تلقائياً.

## سياسة الاحتفاظ
يبقى آخر **60** نسخة (قابل للضبط بـ `SNAP_KEEP`)، وتُحذف الأقدم تلقائياً.
