# تعز الآن — منصة التحقق الذكي

**Taiz Now — Smart Verification Platform**

> لا ننشر ما يُقال... بل نتحقق مما حدث.

منصة يمنية مستقلة للتحقق من الأخبار، رصد الشائعات، كشف الصور المفبركة والفيديو المزيّف،
ونشر التصحيحات المدعومة بالأدلة — بمساعدة الذكاء الاصطناعي ومراجعة بشرية.

## نظرة عامة

منصة `taiznow` تجمع في مكان واحد:

| المكوّن | الوصف |
| --- | --- |
| **الأخبار الموثقة** | أخبار تم التحقق منها مع المصدر والكاتب وتاريخ آخر مراجعة. |
| **مرصد الشائعات** | رصد الشائعات والادعاءات وتحليلها ودرجة خطورتها والردّ بالأدلة. |
| **مركز التصحيحات** | تصحيحات شفافة لما نُشر سابقاً مع توضيح ما تم تعديله. |
| **نظام البلاغات** | إرسال بلاغات (خبر/صورة/فيديو/رسالة) مع إمكانية الإرسال المجهول. |
| **التحقق من الوسائط** | تحليل الصور والفيديو: البيانات الوصفية، كشف التوليد بالذكاء الاصطناعي، التزييف العميق، التحقق الجغرافي. |
| **التحقق من الادعاءات** | تحليل نصي مساعد مع قائمة تحقق ومؤشرات خطر ودرجة ثقة مقترحة. |
| **الخرائط** | عرض المواقع المصنّفة على خريطة تفاعلية للتحقق الجغرافي. |

## منهجية درجة الثقة

الدرجة النهائية من 100 وتُحتسب بأوزان موثّقة:

```
المصدر            25%
المحتوى النصي     20%
الصور             15%
الفيديو           15%
السياق الزمني/المكاني 15%
التدقيق البشري    10%
```

نطاقات التقييم:

| النطاق | المدى |
| --- | --- |
| موثق | 90–100 |
| صحيح | 75–89 |
| صحيح غالباً | 60–74 |
| مشبوه | 40–59 |
| غير صحيح | 0–39 |

> درجة الثقة **استرشادية**: القرار النهائي دائماً للمدقق البشري، ولا يُنشر أي محتوى تلقائياً.

## الأدوار والصلاحيات

| الدور | الوصف |
| --- | --- |
| **مسؤول** (OWNER) | إدارة كاملة للمنصة والمستخدمين. |
| **محرر** (EDITOR) | تحرير المحتوى وإدارة الأخبار. |
| **مدقق الحقائق** (FACT_CHECKER) | التحقق من الأخبار والادعاءات. |
| **محلل إعلامي** (MEDIA_ANALYST) | فحص الصور والفيديو. |
| **محلل جغرافي** (GEO_ANALYST) | التحقق الجغرافي والخرائط. |
| **الناشر الاجتماعي** (SOCIAL_PUBLISHER) | إدارة النشر على الشبكات الاجتماعية. |
| **مشاهد** (VIEWER) | مشاهدة وإرسال البلاغات فقط. |

الصلاحيات مفروضة من الخادم عبر `requirePermission(...)` على كل نقطة API.

## وكلاء الذكاء الاصطناعي

بدل الاعتماد على حسابات بشرية لكل مهمة، تشغّل المنصة **منظومة وكلاء** ينفّذون
دورة العمل تلقائياً على البيانات المخزّنة فقط، دون اختلاق أي وقائع:

| الوكيل | المهمة |
| --- | --- |
| **الجامع** (collector) | جمع الأخبار من المصادر العامة (خلاصات RSS/Google News) وإدخالها كبلاغات. |
| **الراصد** (monitor) | فرز البلاغات الجديدة ورفع أولوية العاجل. |
| **المدقّق** (verifier) | تحليل الادعاءات والوسائط واحتساب درجة الثقة. |
| **الصائغ** (writer) | إعادة صياغة الأخبار الموثّقة بأسلوب صحفي احترافي. |
| **الناشر** (publisher) | توزيع المحتوى المنشور على كل القنوات المفعّلة. |
| **المفنّد** (responder) | صياغة ونشر ردود مدعومة بالأدلة على الأخبار الكاذبة. |
| **الحارس** (guardian) | ينشئ ويزامن صفحات المنصة، يراقب الهوية والبُرد، ويكشف أي تغيير غير مصرّح به ويستعيد الإعدادات المعتمدة. |

| مسار الوكلاء | الوصف |
| --- | --- |
| صفحة `/agents` | لوحة تحكم: تشغيل وكيل، تفعيل/إيقاف، وسجل النشاط. |
| `GET /api/agents` | قائمة الوكلاء وآخر تشغيلاتهم (`agents:manage`). |
| `POST /api/agents/{id}` | تشغيل/تفعيل/إيقاف وكيل (`agents:manage`). |
| `POST /api/agents/autopilot` | تشغيل كل الوكلاء المفعّلين مرة واحدة. |

**الطيار الآلي:** `scripts/autopilot_loop.sh` يشغّل الوكلاء دورياً (كل
`AUTOPILOT_INTERVAL` ثانية، 180 افتراضياً) ويبدأ تلقائياً مع `scripts/start.sh`،
فتستمر المنصة في العمل دون تسجيل دخول.

**جمع المصادر:** يعتمد «الجامع» على خلاصات RSS/Atom العامة المجانية (بلا مفاتيح).
افتراضياً يبحث في Google News بالنسخة اليمنية عن: تعز، اليمن، عدن، صنعاء. يمكن
تحديد مصادرك عبر `SOURCE_FEEDS` (قائمة روابط مفصولة بفواصل). يُستخدم أيضاً
[r.jina.ai](https://r.jina.ai) (بلا مفتاح) لقراءة نص مقال كامل عند الحاجة.

## هوية المنصة والبريد والأمن

- **بريد رسمي باسم المنصة:** صناديق `info@` / `support@` / `noreply@` / `security@`
  على نطاقك (`PLATFORM_DOMAIN`)، تُربط بحساب جوجل للمنصة من صفحة `/platform`.
- **صفحات المنصة:** «الحارس» يسجّل كل مسار ويعطيه سجلاً قابلاً للتتبع، وينشئ صفحات
  جديدة على `/p/{slug}`، ويرصد أي حذف أو تغيير أو إخفاء.
- **مركز الأمن** `/security`: يكشف تغييرات الهوية والبُرد والصلاحيات وكلمات المرور
  والقنوات ومحاولات الدخول الفاشلة، ويقارن الإعدادات بـ«خط أساس معتمد» ويستعيده
  بضغطة واحدة عند الاختراق.
- **تنبيهات فورية:** كل حدث بخطورة «مرتفع/حرج» (تغيير هوية، بريد، صفحة، صلاحية،
  كلمة مرور، جهاز جديد، انحراف إعدادات) يُجدول تنبيهات تُسلَّم إلى قنوات الاسترجاع.
  بلا SMTP تُحفظ الرسائل في «صندوق صادر» مرئي بدل فقدانها؛ و`SECURITY_WEBHOOK_URL`
  يوجّه كل تنبيه إلى محادثة/Webhook.
- **قنوات استرجاع:** بريد احتياطي/هاتف/TOTP من `/security` — تُقنَّع قيمها في الواجهة،
  وتُستخدم مستقبلات للتنبيهات، وتُسجَّل إضافتها/حذفها كحدث أمني.
- **سجل الدخول وكشف الأجهزة:** كل محاولة دخول تُسجَّل (IP/الجهاز/النتيجة)، والدخول
  الناجح من جهاز أو موقع جديد يُرفع حدث «مرتفع» مع تنبيه.
- **واجهات:** `GET/PATCH/POST /api/platform`, `/api/platform/email`, `/api/platform/pages`,
  `GET/POST /api/security` (`scan` | `approve-baseline` | `restore` | `resolve` |
  `dispatch-alerts` | `add-recovery` | `remove-recovery`).

## وسائل التواصل الاجتماعي

صفحة `/social` لإدارة قنوات النشر والحساب المركزي للمنصة:

| الميزة | الوصف |
| --- | --- |
| **ربط حساب جوجل** | ربط حساب المنصة على جوجل وربط القنوات المرتبطة به (يوتيوب). |
| **ربط القنوات** | مكتوبة (X، فيسبوك، تيليجرام، واتساب، لينكدإن) ومرئية (يوتيوب، إنستغرام، تيك توك). |
| **النشر المتعدد** | نشر المحتوى الموثّق على كل القنوات المفعّلة بضغطة أو تلقائياً. |
| **الردود** | نشر بيانات التفنيد على القنوات مباشرة. |

| مسار وسائل التواصل | الوصف |
| --- | --- |
| `GET /api/social` | القنوات والهويات والنشر (`social:manage`). |
| `POST /api/social/connect` | ربط/فصل قناة. |
| `POST /api/social/google` | ربط حساب جوجل. |
| `PATCH /api/social/{id}` | تفعيل/إيقاف قناة. |
| `POST /api/social/publish` | نشر محتوى أو بيان على كل القنوات. |

> **وضعان للنشر:** `MOCK` (افتراضي) يسجّل المنشورات محلياً دون شبكة، و`LIVE` يفعّل
> النشر الحقيقي بمجرد توفير مفاتيح المنصة في متغيرات البيئة (انظر `.env.example`).
> لا تُخزَّن أي مفاتيح داخل الكود.

## التقنية

- **Next.js 15** (App Router) + TypeScript + TailwindCSS
- **PostgreSQL 17** + **Prisma** ORM
- **NextAuth 5** (Credentials + JWT، الدور مضمّن في الجلسة) + bcrypt
- **OpenAI** (اختياري) — بدونه تعمل المنصة بمحرك قواعد محلي حتمي بلا توقف
- **exifr** لقراءة البيانات الوصفية · **Leaflet** للخرائط · **Zod** للتحقق · **Vitest** للاختبارات

## التشغيل

```bash
# تهيئة كاملة: تثبيت التبعيات + قاعدة البيانات + الترحيل + البذور + تشغيل الخدمة
bash scripts/bootstrap_env.sh

# تشغيل/إعادة تشغيل الخدمة والحرس
bash scripts/start.sh
```

يعمل التطبيق على المنفذ `12000` افتراضياً (`PORT` في `.env`).

### الحرس الذاتي (Watchdog)

`scripts/watchdog.sh` يعمل في الخلفية ويراقب دورياً:

1. وجود PostgreSQL — يعيد تشغيله إذا توقّف.
2. صحة التطبيق عبر `/api/health` — يعيد تشغيله إذا تعطّل.
3. فُقدان تبعيات النظام بعد إعادة تهيئة البيئة — يعيد تشغيل `bootstrap_env.sh` كاملاً.

بهذا تبقى المنصة تعمل **تلقائياً** وتتعافى من الأعطال.
